# Project Brief — Axiom Rising

## What
A Fortnite-mechanics-familiar, optimistic light-dystopian math mastery game. Core progression **is** mathematical mastery. Slice 0 ships Algebra I Lesson 1 inside a thin browser 3D training range.

## Goals (Slice 0)
- Playable vertical slice: walk → terminal → explicit lesson → mastery → unlocks
- Versioned content schema + pipeline that emitted Lesson 1
- EN / ES / PL localization
- KaTeX-only math; Web Speech STT/TTS with text fallback
- Static SPA deploy (GitHub Pages / itch.io)
- localStorage/IndexedDB progress; sync-ready models

## Out of scope (Slice 0)
- Accounts/cloud sync, WebRTC social voice, gamepad, full Algebra I graph, combat, multiplayer
